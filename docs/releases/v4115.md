# LocalFit AI v4115（编辑卡优化）

本版是 **个人自用三 ABI APK**，不是 Play 商店/AAB 发行包。安装时需允许「安装未知应用」。

## 本版修复

- **单组编辑卡不再重复**：只有一组时只保留卡底「全部应用 / 忽略」，组头不再画「应用本组」；两组及以上才显示组级按钮。
- **记餐行样式统一**：已有食物和本卡新建食材都显示为紧凑行「序号 + 名称 · 克数 +『新建』徽标 + 状态」，不再在记餐行里放大数字和宏量点。
- **修正误导热量**：新食材的每 100g 热量不再显示成这一份的热量（例如 30g 曲奇不再显示 480 kcal）；每 100g 营养仍保留在独立「新建食材」卡里。
- **「已忽略」徽标**：从薄荷虚线改为中性浅灰实底，不再抢视觉。

## 本版同时包含 v4114 局域网更新

设置 → 关于 → **局域网更新**：填电脑地址（例如 `http://10.26.8.28:8080/`），「检查更新」优先走 Wi-Fi，失败再回 GitHub。v4115 需先手动装一次，之后可在 App 内局域网更新。
