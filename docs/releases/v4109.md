LocalFit AI v4109（2026-11-03）

**根治「AI 不按协议输出 JSON 信封」：信封编译器（强制 JSON）**
- 旧路径的问题：同一次生成既要像人一样说话、又要严格输出 JSON。视觉/小参
  模型经常前者成功、后者失败（看懂了图、写出了完整提案，就是不输出 JSON）；
  再写一条提示词、再催一次，仍然是在赌模型这次听话。
- 新路径：对话流照常生成自然语言；当回复里出现「点应用 / 已记好 / 要不要
  生成」等可执行信号、但信封解析失败时，改发一次**纯文字、强制 JSON** 的
  编译请求：
  * 输入 = 用户请求 + 助手刚才的回复 + 协议/快照；
  * chat-completions 带 `response_format: json_object`，
    Responses 带 `text.format`，JSON 合规由供应商解码层保证；
  * 不再把整段对话和图片重发一遍（更省、更快，也不会再触发一次「散文模式」）。
- 供应商不认 `response_format`（400/422）时自动去掉约束重发一次；仍失败才
  回落到上一版的整轮重跑与散文抢救。
- 编译失败/为空时不会留下隐藏空气泡：最终结果一定会露出来（编辑卡或兜底卡）。

安装包：vc3109 / v4109 / v6109。
