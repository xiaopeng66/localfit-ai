LocalFit AI v4096（2026-11-02）

**修复：今日餐食「推荐候选」点击后黑屏**

根因：候选弹层挂在根导航器上，但候选行用页面自己的 `context` 调 `Navigator.pop`。
真机上页面在分支导航器里，于是被关掉的是整个页面（看起来像黑屏），弹层反而还在。
现在改为用弹层自己的 `sheetContext` 关闭，只关弹层。

同批修正：AI 对话「+」附件三选弹层改为同一种关闭方式，避免同类隐患。

另含 v4095 的全部内容：
- 更新通道改为 GitHub Releases（本仓库），不再使用局域网；
- 下一餐按时刻动态、步数刷新状态、营养目标弹层大字号适配、逐食物勾选删除、
  AI 推荐按剩余营养分配、推荐卡菜单退役、食物自动分类等。
