LocalFit AI v4106（2026-11-03）

**「编辑餐食」条目卡：窄屏 / 大字号自适应（v4105 的补齐）**
- 正常字号：名称 + 删除一行，克数 → 热量 → 宏量同一行，克数与热量相邻。
- 320dp 窄屏：克数 + 热量一行、宏量单独一行，不再挤压宏量。
- 大字号（>1.3×，含 2.0×）：克数、热量、宏量各占一行，热量不再被截成
  「34…」，克数框放得下三位数（320dp × 2.0× 实帧验证）。

**AI 对话「自动接着回复」与暂停后的误警告**（与 v4105 同源）
- 自动催信封的中间气泡不渲染；只有最终编辑卡或最后一次失败的兜底卡露出。
- 用户按「停止」后不再自动催、不弹「没有可执行的操作」兜底卡。

安装包：vc3106 / v4106 / v6106。
