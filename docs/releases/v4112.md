# LocalFit AI v4112（全量审查版）

本版是 **个人自用三 ABI APK**，不是 Play 商店/AAB 发行包。安装时需允许「安装未知应用」。

## 本版修复

- **记录页整卡编辑按餐次隔离**：编辑午餐不会再合并/删除早餐、晚餐。
- **训练回顾删除**：在 StatefulShellRoute 下不再误弹出训练页面。
- **扫码餐食元数据**：烹饪方式与估算克数范围在编辑、部分删除、撤销后保留；来源食物删除后撤销仍保留营养快照。
- **删除/清空/恢复**：食堂地点删除处理全部历史菜单快照与来源；训练计划先清理心肺处方；清空数据先清理识别结果等限制性外键。
- **旧备份兼容**：真实 1.x 备份缺少 profiles/foods 后续字段时按 schema 默认补齐。
- **30 天补记窗口**：仓储层统一拒绝未来日期与超过 30 天的历史餐食。
- **菜单发布失败**：清理本次新建的空食堂/空来源，不留半成品。
- **AI 编辑异常**：数据库/外键失败转为可读失败，不再卡在「应用中」。
- **食堂营养边界**：拒绝负数、超范围、NaN/Infinity、反向热量区间。
- **无障碍**：下载进度条提供「下载进度 / 百分比」语义。
- **自定义餐**：三宏量输入后仍显示 `g` 单位。
