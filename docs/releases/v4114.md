# LocalFit AI v4114（局域网更新）

本版是 **个人自用三 ABI APK**，不是 Play 商店/AAB 发行包。安装时需允许「安装未知应用」。

## 本版新增

- **设置 → 关于 → 局域网更新**：填电脑上跑下载服务的地址，例如 `http://10.26.8.28:8080/`。
- 「检查更新」优先走局域网清单（`lan/manifest.json`），Wi-Fi 下载通常比 GitHub 直连快很多；局域网失败自动回 GitHub。
- 下载、进度、取消、交给系统安装器的流程与原来一致。

**注意**：v4114 本身需要先手动安装一次（浏览器/数据线都行）；装好并配置局域网地址后，后续更新都能在 App 内完成。

## 本版同时包含 v4113 修复

- 修改请求/照片记餐首轮强制 JSON；补信封并回首轮、不再显示重复回复。
- “改记为另一餐”按 `meal.update` 移动；跨餐重复不再假报“已应用”；合并时按全天去重并点名被跳过的食物。
