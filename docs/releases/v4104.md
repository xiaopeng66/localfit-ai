**AI 对话「一直反问要不要生成」**
- 根因：计划类动词（生成 / 安排 / 制定 / 规划 / 配 / 排 / 做一个…）根本不在
  修改动词表里 ⇒ 「帮我生成今天的饮食计划」被判成闲聊 ⇒ 永不催信封；
  模型一句「要不要我帮你生成？」就能无限循环。
- 修复：
  1. 动词表补齐计划类说法（生成/制定/制订/安排/规划/计划一下/配一套/配一餐/
     排一下/排一套/做一个/做个/拟一个/拟个/定个计划/定一个计划）；
  2. 新增回复侧识别 `replyAsksToProceed`：模型在反问「要不要生成/安排」而
     会话里没有待应用卡 ⇒ 自动催信封，用**专门的「不许反问」提示**
     （`chatEditEnvelopeNudgeNoAsking`：用户已明确请求，直接把要做的事写成
     edits，不许用「要不要我帮你生成」代替信封）；
  3. 重启重算口径同步该规则，反问残留重启后仍会给兜底卡。
- 回归：计划类四句判真；反问触发专门催促且提示引用原话；拿到信封出应用卡；
  闲聊被反问时也催一次（反问本身就是失败信号）。
