# LocalFit AI v4113（补信封与改记修复）

本版是 **个人自用三 ABI APK**，不是 Play 商店/AAB 发行包。安装时需允许「安装未知应用」。

## 本版修复

- **AI 修改请求首轮强制 JSON**：照片记餐或明确修改请求不再先回一段散文、再补跑一次；供应商不支持 JSON 模式时才走有界降级。
- **补信封不再显示**：自动补跑拿到信封后，编辑卡并回**首轮气泡**，补跑气泡删除；最终仍失败也不显示补跑文字，只保留首轮 + 手动重试入口。
- **“改记为午餐”按移动处理**：协议要求已记的一餐改餐次用 `meal.update(mealId, slot)`，不再用 `meal.create`。
- **跨餐重复不再假报“已应用”**：`meal.create` 若这些食物已经在另一餐，返回失败并提示改餐次；同餐合并的部分重复会点名被跳过的食物。
- 合并餐次时按**全天**去重，避免午餐已有米饭时晚餐再算一份。
