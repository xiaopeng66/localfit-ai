## 3. 同主题补齐八组完整设计

这些是**现有业务的视觉与状态补全**，不承诺扩建新业务。每组先产出布局、字段/按钮、状态、真实入口和返回值规格；长流程用完整二级页，简单确认才用弹层。所有失败都在当前层可见并保留输入，不能统一退成“知道了”。

### 3.1 引导、资料与头像

沿用“基本资料—目标—安全筛查”连续分组卡和顶端阶段条，底部固定确认；阶段条只表示**单页滚动进度**，不得变成强制分步新业务。补年龄、性别、身高、体重、活动水平、目标体重、目标范围确认及成人/特殊健康风险分支。

资料编辑必须回填已有字段；未知性别保持未选择。水量/步数目标留空表示不改，未改水目标不新增版本。头像涵盖选择、取消、失败、缺文件回退；昵称不能代替完整资料页。补保存中、错误留页和成功返回刷新。

### 3.2 拍照、候选修正与餐食编辑

采用二级整页：顶部为图像、当次发送范围和接收方，下面为互斥的结果/编辑区域。候选行包含来源、本地匹配、克数、移除/修正；底部为餐次、备注和确认入账。

补处理中、取消、无结果、匹配歧义、剩餐净摄入、候选变更和保存失败。识别结果不得直接落库；只有用户确认才记为已吃。“已保存但图片清理未完成”必须与“未保存”分开，并继续阻止重复提交。

### 3.3 菜单来源与食堂目录

按地点、窗口、菜品下钻，复用现有 `CanteenDirectoryPage` / `MenuTabView` 业务入口。补搜索、空态、加载、新建、编辑、删除、照片选择、分析及收录结果。来源/营养不完整、菜单过期、无候选不能显示成可直接确认的完整推荐。

菜品估算按现有入口交接聊天，不恢复已退役的任务执行管线。“加入”究竟写今天已吃还是编辑推荐，必须在按钮文字和确认内容上明确，不能一键同时创建推荐与摄入事实。

### 3.4 AI Provider 配置

使用同主题表单容纳三种协议、HTTPS Base URL、模型、推理设置和 Key。连通性测试与模型查询结果就地展示，模型列表支持筛选；保存、测试、清除 Key 是独立动作。

分别设计未配置、测试中、认证失败、网络失败、成功但无模型、保存失败、清 Key 二次确认。Key 已保存时留空表示保持，不回显明文。保存成功不等于网络连通，模型列表有名字不等于模型可调用。

### 3.5 AI 对话、可执行提案与安全反馈

沿用气泡视觉，增加逐条“新增/修改/删除”摘要、目标识别及待应用/应用中/已应用/失败/忽略状态。删除用危险样式，不给整组命令统一绿勾；应用失败显示具体条目，重复点击不能重复执行。

补流式停止、失败重试、历史加载失败、图片已清理以及明确的发送披露。应用前不写库，目标继续使用真实 ID。当前训练命令已核实的是创建和删除，不能把原型里的“编辑训练日”说明写成已支持的新协议。

### 3.6 备份、恢复、CSV 与清理

备份保留两次口令输入；恢复明确覆盖范围和不可逆后果。CSV 先展示可导入、重复、格式错误三本账与重复样例，再选择跳过或全部导入，最后单事务写入。

分别补取消、解析失败、写入失败、导出失败、恢复失败和成功刷新。清内置食物与清全部数据是不同动作；全清保留文字确认。部分媒体清理失败不能显示“数据未受影响”，也不能让用户误以为整事务未发生。视觉规格不能更改现有 21 列结构或重复规则。

### 3.7 步数、权限与电子秤

分开设计未授权、拒绝、不支持、读取中、失败、成功。秤同步保留同日体重覆盖冲突确认。入口未接依赖时保持既有隐藏或诚实说明，不能画成已经连接。

标准协议能力与厂商接口预留要分别标注；小米等厂商挂点并不等于已适配设备。原型上的样例步数不证明传感器可用。

### 3.8 数据来源、许可、帮助与隐私

补数据来源清单、开源许可可滚动长页、帮助和反馈的真实边界。隐私说明区分本地保存、用户触发的外发、发送字段及接收方，不再用“本地优先”概括所有流向。

沿用已下线来源的历史许可说明，不恢复随包种子。旧聊天底部 `ChatDisclaimer` 组件已删除；Round7 的医学提示是另一段文案，本指南默认不新增常驻医学提示，若恢复需另行确认。既有训练疼痛/总结中的场景化安全提示及真实外发披露继续保留，不能随视觉清理一起删除。

## 4. 视觉规范怎样落到原生

### 4.1 推荐视觉方向

沿用 LocalFit 的雾白/深绿底、薄荷主色及营养分类色，图表承担信息而非装饰；左对齐主内容，数值右对齐或沿环心对齐，标题与操作共享基线。卡片用于界定独立任务，不把每句说明都包成同样的卡。

字体继续使用平台中文字体与等宽数字特性，不引入远程字体。正文以 14sp 为基础，标题、辅助信息、数值建立有限字阶；原型的 550/650/750 字重必须映射到设备实际可用字重并审看，不能假定浏览器与 Flutter 渲染一致。关键信息不可为了复刻小字而压到不可读。

## 5. 不可变行为与退役边界

每一实施包须把相关项目列入“不变项”，同时验收 UI 与业务；“页面看起来一样”不够。

1. **导航与共享壳**：保留 IndexedStack、资料 push/pop、今日到菜单通知、AI 创作一次性交接；使用正确弹层 context，不能 pop 主分支。保留键盘避让、安全区、固定提交区、取消返回值及输入焦点。
2. **资料与目标**：回填真实字段，未知性别不伪造；空目标不覆盖旧值，未变水目标不新增版本；假数据不能填真实空卡。
3. **饮食与目录**：日期和记录一致，增删改/批删/撤销更新趋势、均值与常驻列表；旧请求不能覆盖新查询。菜单添加记今天，历史补录走编辑；目录变更不改已记录快照。CSV 失败不得留下半批写入。
4. **识别**：保留忙状态互斥、取消、候选修正、本地匹配和剩餐编辑；用户确认前不写餐。保存后媒体清理失败仍防重入，外发披露保持独立。
