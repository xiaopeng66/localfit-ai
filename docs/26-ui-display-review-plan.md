## 2. 审查矩阵

| 场景 | 宿主测试条件 | 重点判据 |
|---|---|---|
| 常规竖屏 | 360/390/430dp，字号 1.0 | 数字与单位可读；短按钮标签不被拆碎；左右留白、对齐和操作区合理 |
| 窄屏 | 320×640dp，字号 1.0/1.3 | 长名称正常换行；数值不占尽标题宽；操作区能换行/纵向布局 |
| 大字 | 320/390dp，字号 2.0 | 无静默截断、固定高裁剪、单字符竖排或按钮文字出界 |
| 矮屏与键盘 | 390×568dp，键盘 240–300dp | 表单正文能滚；保存/取消在键盘上方且实际可点 |
| 安全区 | 顶 48dp / 底 24dp | 首屏避让；滚到底最后内容与导航/FAB不重叠 |
| 数据状态 | 空态、有真实合成数据、长名称/长数值、错误/等待态 | 不用空态冒充错误；状态变更不丢按钮；长文本不掩盖信息 |
| 配色与系统 | 亮/暗色，正常/大字设备截图 | 可读性、背景层级、触达区域、实际绘制范围 |

布局约束宽度以逻辑 dp 计。宿主测试字形与 Android 实际字体不同，故测试负责机制和边界，设备截图负责最终呈现。真实 Android 2.0 系统字号是非线性缩放，记录系统设置值而不假定每个字号都线性乘二。

## 3. 六条检查轴

1. **文字**：短标签合理断行，长标题完整可读，单位和数值不被无意义拆开；检查 `RenderParagraph.didExceedMaxLines` 与实际行盒。
2. **按钮**：≥44dp 命中区域，标签包含在按钮内，按钮之间无交叠；点击外框而非只点中心也能执行。
3. **排列**：固定宽、高和 Row 的组合是否挤压；放不下时改布局，而非削掉内容。
4. **遮挡**：状态栏、底栏、FAB、键盘、模态层和裁剪祖先；布局矩形不等于可见矩形。
5. **滚动**：懒列表真实滚到末项；选中日期/筛选项可见；弹层正文滚动与底部操作区分开。
6. **状态**：等待、错误、保存中、恢复后等状态下操作仍有清楚位置和反馈。

## 4. 执行顺序

- 共享组件：SettingRow、LfCircleIconButton、WeekStrip、AppSheet、顶部/底部操作栏、指标卡与聊天输入。
- 主页面：今日→饮食三页→我的→训练→AI。
- 二级页面和表单：引导/档案、训练计划、拍照结果/编辑、食堂维护、食物编辑、AI 配置和备份。
- 每个候选先复现再登记：页面、状态、宽高/字号、根因、前证据、修复位置、回归判据。
- 每项修复先写能失败的测试；修复后跑聚焦测试。关键机制做隔离回退/变异，并按字节还原。
- 最后完整 format/analyze/test，构建同源 x86_64 包做设备复验，生成 arm64 简化 APK。

## 5. 证据纪律与退出条件

只检查控件存在、无 RenderFlex 异常或直接调用 onPressed，不能证明布局和操作正确。本轮新增断言必须观察可读、包含关系、几何、实际 hit test 或用户动作。原有测试不可用放宽断言的方式消红。

源码与原交付件修改前备份；本项目无 Git。临时文件只在 `E:/AI/Zcode/tmp/`。仅操作 LocalFit `emulator-5556`，不操作 5554/5558。全程 fake provider、零真实 AI 请求，凭据不进入日志、文档和截图。

退出条件：已证显示缺陷全部修复；新增回归先红后绿；完整门禁通过；设备正常/大字/弹层截图复验完成；更新证据和 STATUS；新包验证 ABI、签名、版本、大小与 SHA-256，保留匹配混淆符号。未取得的真机/硬件/真实 AI 证据如实列明。
