## 为什么有的动作显示「难度未知」？

难度和常用度是可空字段。历史动作没标注就显示「未知」，
应用不会拿一个默认值冒充真实标注。

## 步数读不到怎么办？

「设置 → 步数与身体活动」里能看到三种状态：已授权 / 未授权 / 设备不支持。
未授权时可以点卡片申请权限，或在系统设置里打开「身体活动」权限；
设备没有计步传感器时会如实说明，不会显示一个假的 0 步。

## 电子体重秤怎么同步？

上秤后点「授权并开始同步」：只在 App 前台扫描约 10 秒，读到一次体重就停，
读数只写本机数据库并标为「秤同步」。

只支持标准体重秤协议（Bluetooth SIG 体重秤服务）；厂商私有协议
（例如部分小米秤）暂不支持，会如实提示。同步需要系统「附近设备（蓝牙）」
权限；该权限只用于扫描与连接秤，不用于获取位置。

## 想反馈问题？

「我的 → 关于 → 反馈」里有 GitHub 仓库链接与「复制环境信息」按钮。
App 没有内置上报通道，出错不会自动回传；复制出的内容由你决定贴到哪里。
